# Hello, world!

Данный код позволяет определить, какому фильму было выставлено больше всего оценок 5.0. Дано 2 файла: movies.csv, в котором перечислены фильмы, и ratings.csv, где собраны оценки пользователей этих фильмов.
Вначале код объединяет эти файлы, потом фильтрует по рейтингу, и считает распределение частот.
